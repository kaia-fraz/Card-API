# Card API

1. Clone the Repo

2. Install Dependencies 
- npm install

3. Run node server


# Endpoints

## cards: '/cards'
    shows all cards

## users: '/users'
    shows users
## auth: '/auth'
    creates a token

## createCard: "/cards/create"
    -creates card

## updateCard: "/cards/update/:id"
    updates card
## deleteCard: "/cards/delete/:id/:token"
    deletes card

## cardCount: "/cards/count"
    counts how many cards there are 

## randomCard: "/cards/random"
    generates a random card
